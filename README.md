# Quick Controls

Минимальное Android-приложение: два ползунка — громкость (media) и яркость экрана.

## Как собрать APK с телефона (без Android Studio)

1. Создай пустой репозиторий на github.com (можно прямо с телефона в браузере или в приложении GitHub).
2. Загрузи в него все файлы из этого архива, сохранив структуру папок
   (`app/...`, `.github/workflows/build.yml`, и т.д.) — через
   "Add file → Upload files" в браузере, или через приложение GitHub.
3. Как только файлы запушены в ветку `main`, GitHub Actions сам запустит сборку
   (или зайди во вкладку **Actions** и запусти workflow "Build APK" вручную).
4. Через 1–2 минуты открой завершённый run → внизу раздел **Artifacts** →
   скачай `quick-controls-apk` — внутри `app-debug.apk`.
5. Установи apk на телефон (разреши установку из неизвестных источников,
   если попросит).

## Про яркость

Изменение системной яркости требует специального разрешения
`WRITE_SETTINGS`, которое нельзя выдать обычным диалогом — в приложении есть
кнопка "Разрешить менять яркость", она открывает нужный экран настроек.
Без этого разрешения ползунок яркости всё равно будет менять яркость
текущего окна приложения (визуально), но не будет сохранять её в систему.
